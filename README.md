# 车联智护 Agent —— 智能维保与动态出行规划系统

基于多模态车载数据的一体化维保预约与动态出行规划 Agent，融合汽车后服务与出行服务，实现故障预警 → 智能诊断 → 自动预约 4S 店 → 代取送车/上门保养 → 支付结算的真实闭环。

## ✨ 核心亮点

- **多 Agent 协同**：车况监测、维保调度、出行规划、服务履约四大 Agent 协同工作
- **多模态交互**：支持语音/文字输入，接入 OBD 数据、地图视觉
- **全链路闭环**：故障预警 → 智能诊断 → 自动预约 → 进度跟踪 → 支付结算 → 健康档案同步

## 🧠 Agent 能力矩阵

| Agent | 核心能力 | 输入 | 输出 |
|-------|---------|------|------|
| **车况监测** | OBD 故障码解析、胎压/刹车片/机油寿命预测、综合健康评分 | OBD 实时数据 | 健康报告、告警消息 |
| **维保调度** | 门店查询排序、工位排班匹配、配件库存检测、估价单生成 | 故障码列表 | 预约工单、估价单 |
| **出行规划** | 多路线对比、充电站规划、休息点推荐、天气预警、出发前自检 | 起终点、日期 | 路线方案、补能计划 |
| **服务履约** | 预约确认、代驾分配、进度跟踪、支付结算、健康档案同步 | 工单信息 | 支付记录、服务报告 |

## 🔌 提示词交互示例

| 输入 | 触发 Agent | 响应 |
|------|-----------|------|
| "发动机故障灯亮了" | 车况监测 | 解析 OBD 故障码 → 诊断报告 → 推荐预约 |
| "明天出差去上海" | 出行规划 | 路线规划 → 充电站点 → 自检清单 |
| "帮我预约最近的 4S 店" | 维保调度 | 门店查询 → 工位匹配 → 创建工单 |
| "查看车辆状态" | 车况监测 | 综合健康评分 → 问题列表 → 建议 |

## 🛠️ 技术栈

- **框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **样式**: Tailwind CSS 3
- **图标**: Lucide React
- **状态管理**: React Hooks

## 📋 合规边界

- 车辆数据需经车主授权，故障码不上传原始 VIN
- 维修估价透明，涉及安全项必须人工确认
- 模拟数据仅用于演示，生产环境需接入真实 API
